# 📚 StudyPulse – Smart Study Session Analyzer

StudyPulse is a Python-based desktop application that helps students track and analyze their study sessions.

The application takes study details such as subject, duration, focus, energy, and distraction level, then calculates a productivity score out of 100. The collected data can be analyzed through an interactive dashboard.

## ✨ Features

- 📖 Record study sessions
- ⏱️ Track study duration
- 🎯 Measure focus level
- ⚡ Track energy level
- 📱 Track distraction level
- 📊 Calculate productivity score
- 💾 Save study data in CSV format
- 📈 Interactive productivity dashboard
- 🔍 Hover over charts to view detailed information

## 🛠️ Technologies & Libraries

- **Python**
- **Tkinter** – Graphical User Interface
- **messagebox** – Error and success notifications
- **Pandas** – Data handling and CSV management
- **Plotly** – Interactive data visualization
